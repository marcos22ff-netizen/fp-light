# FP Light

Site institucional da FP Light, responsivo para celular e computador. Publicado como site estático pelo GitHub Pages.

## Prévia local

Na pasta deste projeto, execute:

```powershell
python -m http.server 8000
```

Depois abra `http://localhost:8000` no navegador.

## Conteúdo

- Página em HTML, CSS e JavaScript, sem etapa de compilação.
- Abertura cinematográfica com quadros para telas desktop e mobile.
- Modelo 3D interativo do Moving Head.
- Contato e pedidos de orçamento pelo WhatsApp.
